# Production Workflow

Use this reference for full carousel production and automation design.

## Stage map

| Stage | Output | Gate |
|---|---|---|
| Intake | Brief contract | Audience and learning outcome are explicit |
| Research | Source notes and theme clusters | Claims are current and themes are distinct |
| Strategy | Recommended angle | User understands why the post deserves to exist |
| Storyboard | Slide-by-slide plan | One lesson per slide and a complete narrative arc |
| Visual system | Design specification | Layout and brand rules are stable |
| Draft | Reviewable carousel | Clearly labelled DRAFT |
| Revision | Scoped change list | Approved work remains locked |
| Final QA | Verified files | Every asset opens and passes content/visual checks |
| Package | Ordered final package | One source of truth; no mixed drafts |
| Post review | Performance insight | Next action is tied to the original objective |

## 1. Intake

Capture:

- Topic.
- Audience.
- Learning outcome.
- Objective.
- Brand role.
- Tone.
- Language.
- Source material.
- Desired slide count.
- Deadline and approval owner.

Reject vague outcomes such as “make it informative.” Replace them with an observable outcome such as “help a junior bartender recognise five menu directions and discuss where each fits.”

## 2. Research

Build a compact evidence table:

| Signal | Source | Date | Evidence type | Confidence | Possible lesson |
|---|---|---|---|---|---|

Evidence types:

- Verified fact.
- Industry observation.
- Expert opinion.
- Brand-owned claim.
- Personal interpretation.

Use recent sources for current trends. Keep source language out of the carousel unless direct quotation is necessary and permitted.

## 3. Angle selection

Generate up to three angles, then score each from 1–5:

- Audience fit.
- Educational value.
- Originality against recent posts.
- Visual potential.
- Source strength.
- Brand fit.
- Save/share potential.

Select the strongest total, but use judgement when a high-scoring angle still feels generic.

## 4. Storyboard

Give every slide a job. A slide that merely repeats the cover, caption, or previous slide should be removed or merged.

Recommended arc:

1. Hook.
2. Context or behaviour shift.
3. Core lesson sequence.
4. Practical interpretation.
5. Recap or checklist.
6. CTA aligned with the objective.

Keep one primary idea per slide. Use supporting copy to clarify, not to introduce a second topic.

## 5. Visual specification

Define before producing:

- Canvas and safe margins.
- Grid and repeated positions.
- Type hierarchy.
- Palette and accent rules.
- Photography or illustration direction.
- Lighting and colour grading.
- Numbering system.
- Product, glass, garnish, and logo rules.
- Maximum text density.

For automated Canva production, use editable layers and named variable fields. A flattened PNG is a delivery asset, not a reusable template.

## 6. Draft review

Review in this order:

1. Audience value.
2. Narrative logic.
3. Claim accuracy.
4. Text density.
5. Visual hierarchy.
6. Brand consistency.
7. Technical export.

Do not spend time perfecting pixels while the angle or learning outcome is still weak.

## 7. Revision protocol

Translate comments into:

- Slide ID.
- Requested change.
- Reason.
- Elements to preserve.
- Re-review criteria.

Example:

> Slide 06 — make the garnish visibly savoury; preserve headline, number placement, background, and copy.

Return a change log with:

- Changed.
- Preserved.
- Still open.

## 8. Packaging

Package:

- Ordered final images.
- Selected caption.
- Alt text.
- Sources.
- Upload instructions.
- Canva master or editable source when available.

Use zero-padded filenames and one final directory. Never mix draft, review, audit, and approved files.

## 9. Performance loop

Match metrics to the objective:

- Education: saves, shares, meaningful comments.
- Discussion: comments and comment quality.
- Awareness: reach, profile visits, follows.
- Conversion: clicks, enquiries, downloads, or bookings.

Record what worked, what underperformed, and the single change to test next.
